# Безопасность

Сообщайте о проблемах безопасности сопровождающим проекта конфиденциально, не создавая публичный issue. Не включайте в сообщения приватные ключи, токены регистрации или сгенерированные профили.

Сервис изначально построен без хранения состояния. Он намеренно не сохраняет приватные ключи, токены регистрации, сгенерированные конфигурации, cookies или данные аналитики. Ответы API используют `Cache-Control: no-store`; внешние запросы имеют timeout, а чувствительные значения не записываются в логи.

При деплое следует поддерживать зависимости в актуальном состоянии, использовать HTTPS и настраивать контроль доступа платформы в соответствии с документацией провайдера. Внешний WARP API остаётся сторонней зависимостью, поэтому к нему применяются его собственные условия использования и политика конфиденциальности.
